# 📂 Code Snippet Organizer

A lightweight, terminal-based tool written in **C++** that helps developers **save, tag, and search code snippets locally**.  
Think of it as your personal mini-repository for reusable code.

---

## ✨ Features
- **Add Snippets**: Save code with a title, description, and tags.
- **Search Snippets**: Find snippets by keyword, tag, or language.
- **Categorization**: Organize snippets by programming language or custom categories.
- **Export/Import**: Backup snippets to JSON/CSV and share with others.
- **CLI Interface**: Simple commands like `add`, `search`, `list`, `delete`.
- **Persistence**: Stores snippets in local files (JSON or SQLite).

---

## 🛠️ Tech Highlights
- **Object-Oriented Design**: Classes for `Snippet`, `SnippetManager`, and `DatabaseHandler`.
- **File Handling**: JSON or SQLite for storage.
- **STL Containers**: Uses `vector`, `map`, and `unordered_map` for efficient indexing.
- **Search Algorithm**: Keyword-based search with partial matches.
- **Cross-Platform**: Works on Linux, Windows, and macOS.
